# פתיחת ספרייה — Otzaria Open Plus

תוסף לאוצריא שמקשר את כפתור `+` אל מסך הספרייה המקורי, בלי להשאיר לשונית תוסף מיותרת.

**יוצר התוסף:** אברהם mch

## התנהגות

- לחיצה על `+`: אוצריא פותחת את דף התוסף עם אירוע שמכיל `source: "newTabButton"`. התוסף מזהה את המקור, מנווט אל `navigation.goTo({ target: "library" })`, מאתר את הלשונית שלו באמצעות `reader.getCurrentState()` והשדה `isSelf`, וסוגר אותה באמצעות `reader.closeTab()`.
- פתיחה ידנית של התוסף: מציגה דף מידע מינימליסטי עם סמל ספר ושם היוצר. היא אינה מפנה אוטומטית לספרייה.
- רישום כפתור `+`: מתבצע במופע הרקע בעת עליית אוצריא. אם תוסף אחר כבר מחזיק בכפתור, אוצריא עשויה להציע למשתמש לבחור בעלים.

## מבנה

- `manifest.json` — תוסף רגיל עם דף גלוי ומופע רקע נפרד.
- `index.html` + `app.js` — דף המידע והטיפול בלחיצה על `+`.
- `background.html` + `main.js` — רישום כפתור `+` ברקע.

## הרשאות

- `navigation.write` — רישום כפתור `+` וניווט לספרייה.
- `reader.open` — איתור וסגירת לשונית התוסף.
- `app.run_on_startup` ו-`app.startup_contributions` — הפעלת הרישום ברקע בעליית אוצריא.
- `events.subscribe:theme.changed` — התאמת צבעי הדף לשינוי ערכת הנושא.

## בדיקה

GitHub Actions מריץ בדיקת תחביר JavaScript, אורז באמצעות ה-packager הרשמי של אוצריא, מאמת את תוכן חבילת `.otzplugin` ומעלה אותה כ-artifact.

בדיקת CI אינה מחליפה בדיקה בתוך אוצריא עצמה. לאחר התקנה יש לבדוק:
1. לאשר את ההרשאות הנדרשות.
2. להפעיל מחדש את אוצריא ולוודא שהרישום של `+` הצליח.
3. ללחוץ על `+` ולוודא שמסך הספרייה נפתח ושאין לשונית תוסף נוספת.
4. לפתוח את התוסף ידנית ולוודא שדף המידע נשאר פתוח.
5. לשנות ערכת נושא ולוודא שצבעי הדף מתעדכנים.

## אריזה
