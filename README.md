# Otzaria Open Plus

תוסף ניסיוני ללא HTML, המבוסס על **JavaScript בלבד** ועל `manifest.json`.

**שם היוצר:** אברהם mch

## מטרה
לשייך את לחצן `+` לספרייה המקורית של אוצריא.

## מצב תאימות חשוב
בגרסת ליבת אוצריא שנבדקה, `plugin.setNewTabPage` רושם בעלות על `+`, אך הקלקה עליו מפנה דרך `PluginPageLauncher` לדף התוסף. לעומת זאת, לתוסף `headless` אין דף או לשונית כלל. לכן אין עדיין אישור שלחיצה על `+` אכן תגיע לאירוע JS ותפתח את הספרייה. **המימוש הזה אינו מוגדר גרסה יציבה ואין לטעון שהוא פועל מקצה לקצה.**

הקוד:
- נרשם עם `plugin.setNewTabPage({enabled:true})` כשהמנוע מופעל ב-`app.startup`.
- כולל ניווט לספרייה המקורית עם `navigation.goTo({target:"library"})` אם מתקבל `plugin.page_opened` ממקור `newTabButton`.
- אינו מכיל קובץ HTML או ממשק משתמש.
- אינו משנה את ליבת אוצריא.

## בדיקה באוצריא
1. ארוז את התיקייה באמצעות `otzaria.exe pack-plugin <path>` בגרסה תומכת.
2. התקן, אשר את ההרשאות `navigation.write` ו-`app.run_on_startup`.
3. הפעל מחדש את אוצריא, בדוק שהכפתור מופיע ואז לחץ עליו.
4. ודא שהספרייה המקורית נפתחת **ללא שום כרטיסייה מיותרת**. אם לא — זו מגבלת מנגנון ה-`+` הקיים, ולא כדאי להפיץ תוסף זה כפתרון מלא.

מבוסס על תיעוד אוצריא ועל `PluginNewTabPageRegistry` / `PluginPageLauncher`.
