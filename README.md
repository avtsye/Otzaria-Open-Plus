# מוסיף+ — Otzaria מוסיף+

תוסף לאוצריא שמאפשר להפעיל או לכבות את השימוש בכפתור `+` מתוך מסך התוסף. כשהכפתור פעיל, לחיצה עליו פותחת את מסך הספרייה המקורי של אוצריא.

**יוצר התוסף:** אברהם mch

## התנהגות

- פתיחה ידנית של התוסף מציגה מסך הגדרות קטן ונקי, עם מתג להפעלה או לכיבוי של כפתור `+`.
- כשהמתג פעיל: כפתור `+` פותח את הספרייה המקורית, ולשונית התוסף נסגרת לאחר הניווט.
- כשהמתג כבוי: התוסף משחרר את הרישום של כפתור `+`.
- ההעדפה נשמרת באחסון התוסף ונשמרת גם לאחר הפעלה מחדש של אוצריא.
- משתמשים שמשדרגים מגרסה קודמת מקבלים כברירת מחדל כפתור פעיל, כמו בהתנהגות הקודמת.

## עיצוב

המסך משתמש בצבעי ערכת הנושא ובגופן הממשק של אוצריא, ומתעדכן כאשר ערכת הנושא משתנה. הממשק מצומצם: סמל קטן, כותרת, הסבר ומתג יחיד ללא כרטיסים או קישוטים מיותרים.

## הרשאות

- `navigation.write` — רישום או שחרור כפתור `+` וניווט לספרייה.
- `reader.open` — איתור וסגירת לשונית התוסף.
- `plugin.storage.read` ו-`plugin.storage.write` — שמירת מצב המתג.
- `app.run_on_startup` ו-`app.startup_contributions` — הפעלת הרישום ברקע בעליית אוצריא.
- `events.subscribe:theme.changed` — התאמת צבעי הדף לשינוי ערכת הנושא.

## בדיקה

GitHub Actions מריץ בדיקת תחביר JavaScript, אורז באמצעות ה-packager הרשמי של אוצריא, מאמת את תוכן חבילת `.otzplugin` ומעלה אותה כ-artifact.

לאחר התקנה יש לבדוק בתוך אוצריא:
1. לפתוח את התוסף ולוודא שהמתג מופיע במצב פעיל כברירת מחדל.
2. לכבות את המתג, לסגור ולפתוח מחדש את אוצריא ולוודא שכפתור `+` לא משויך לתוסף.
3. להפעיל מחדש ולוודא שהספרייה נפתחת בלחיצה על `+`.
4. לשנות ערכת נושא ולוודא שהממשק מתאים את צבעיו.

## אריזה

ה-workflow משתמש ב-`PluginPackager.packDirectory` מתוך קוד אוצריא ומפיק:
`dist/otzaria-open-plus.otzplugin`.
